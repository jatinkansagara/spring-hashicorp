# Spring Boot HashiCorp Vault Transit Integration

This repository demonstrates how to integrate HashiCorp Vault's **Transit Secrets Engine** with a Spring Boot application to achieve Encryption-as-a-Service (EaaS). By offloading cryptographic operations to Vault, this project ensures that sensitive data is encrypted in transit without exposing raw cryptographic keys to the application layer.

## Project Structure

The codebase is organized with a clear separation of concerns, abstracting the cryptographic logic into a dedicated service layer:

```text
spring-hashicorp/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/com/visions/
    │   │   ├── SpringVaultApplication.java
    │   │   ├── controller/VaultController.java
    │   │   └── service/VaultTransitService.java
    │   └── resources/
    │       └── application.yml
    └── test/
```

## Prerequisites

* **Java:** JDK 17 or higher
* **Build Tool:** Maven 3.8+
* **Vault:** A running instance of HashiCorp Vault (local dev server or enterprise)

## Vault Environment Setup

Before starting the Spring Boot application, you must start a local Vault server, enable the Transit engine, and create the required encryption key.

1. **Start Vault in development mode:**
   ```bash
   vault server -dev -dev-root-token-id="00000000-0000-0000-0000-000000000000"
   ```

2. **Set the Vault address environment variable:**
   ```bash
   export VAULT_ADDR='http://127.0.0.1:8200'
   ```

3. **Enable the Transit Secrets Engine:**
   ```bash
   vault secrets enable transit
   ```

4. **Create the encryption key:**
   ```bash
   vault write -f transit/keys/order-encryption-key
   ```

## Application Configuration

Ensure your `src/main/resources/application.yml` matches your Vault environment. The default configuration uses the dev root token:

```yaml
spring:
  cloud:
    vault:
      host: 127.0.0.1
      port: 8200
      scheme: http
      authentication: TOKEN
      token: ${VAULT_TOKEN:testing-token}
      transit:
        enabled: true
vault:
  transit:
    key-name: ${VAULT_TRANSIT_KEY_NAME:my-app-key1}
```

## Running the Application

Compile and run the Spring Boot service using Maven:

```bash
mvn clean install
mvn spring-boot:run
```

The application will start on `http://localhost:8080`.

## API Endpoints

### 1. Encrypt Data
Accepts plaintext and returns ciphertext generated by Vault.

**Request:**
```bash
curl -X POST http://localhost:8080/api/v1/vault/encrypt \
  -H "Content-Type: application/json" \
  -d '{"data": "My Highly Sensitive Enterprise Data"}'
```

**Response:**
```json
{
  "ciphertext": "vault:v1:..."
}
```

### 2. Decrypt Data
Accepts ciphertext prefixed with `vault:v1:` and returns the original plaintext.

**Request:**
```bash
curl -X POST http://localhost:8080/api/v1/vault/decrypt \
  -H "Content-Type: application/json" \
  -d '{"ciphertext": "vault:v1:..."}'
```

**Response:**
```json
{
  "plaintext": "My Highly Sensitive Enterprise Data"
}
```
